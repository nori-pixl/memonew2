# norimemo 使い方（Web版）

メモ帳のHTML（`assets/index.html`）の使い方です。画面上部のメニュー「ファイル / 表示 / 挿入 / 操作 / ツール / 設定」から機能を呼び出します。左のサイドバーにフォルダとファイルが並びます。

> アプリ版（Expo）でも同じ画面が動きます。アプリ版だけの機能は最後の「アプリ版だけの機能」にまとめています。

## 基本
- 左のサイドバーで **「＋ 新規フォルダ」** を押してフォルダを作り、その中にファイルを作って書きます。
- 並び替えは「表示」→「並び替え」で、名前順・更新日時順（新しい順）・タグ順から選べます。
- ファイル名の変更・複製・削除などは、ファイルを選んだときのメニュー（名前を変更 / 複製 / 削除）から行います。
- 画面下のステータスバーに、現在のファイルと文字数が出ます（「表示」→「ステータスバーの表示」で切り替え）。

## ファイルメニュー
| 項目 | できること |
|---|---|
| 保存 | 現在のメモを保存 |
| テキストとして保存 | `.txt` として書き出し |
| 画像として保存（PNG） | メモを画像にして保存 |
| Markdownとしてエクスポート | Markdown形式で書き出し |
| Markdownを開く（新規ファイル） | Markdownファイルを新しいメモとして読み込み |
| 印刷 / プレビュー | 印刷画面・プレビューを開く |
| 共有 | メモの共有（アプリ版では「HTTPで共有」あり） |
| このフォルダをPDFでダウンロード | フォルダ内のメモをまとめてPDF化 |
| このフォルダを印刷 | フォルダ内のメモをまとめて印刷 |
| JSONを開く | 書き出したJSONを読み込み |
| メールを送信（現在のファイル） | 現在のファイルをメールで送る |
| バージョン履歴 | 以前の状態を一覧し、復元 |

## 表示メニュー
- **拡大 / 縮小 / 100%**: 文字の大きさ
- **ダークモード**、**ステータスバーの表示**、**タブモードの表示**、**ルーラーの表示**、**左に行番号を表示**
- **印刷メモ帳を有効にする**: 印刷向けのレイアウトで書く
- **Enterキーで「・」を自動追加**: 改行のたびに箇条書きの「・」を入れる
- **Markdownモード / HTMLモード / Monacoエディターモード**: 書き方（エディタ）を切り替え
- **ToDoリスト表示**: チェックボックス付きのToDo表示
- **縦書きモード**: 縦書きにし、「右から書く / 中央から書く / 左から書く」「上揃え / 中央揃え / 下揃え」で位置を決める
- **予測変換の位置を変える**
- **並び替え**: 名前順 / 更新日時順 / タグ順
- **フォント**: MiSans（標準）、ゴシック体（端末の標準）、游ゴシック、明朝体、教科書体風、等幅（コード風）、手書き風
- **キーボードの種類**: 通常（文字）/ 数字 / 電話番号 / メールアドレス / URL / 小数 / 検索 / キーボードを表示しない

## 挿入メニュー
- **画像挿入**
- **図形**: 四角形・円・三角形・線・矢印。色は「図形の色」で決め、「選択中の図形に適用」で既存の図形の色を変えます。
- **グラフ（エクセル経由）**
- **Markdown書式**: 見出し1〜3、箇条書きリスト、番号付きリスト

## 操作メニュー（右クリックメニューにもあります）
- 選択を開始、↑ ← → ↓（カーソル移動）、切り取り、コピー、貼り付け、削除
- 戻る、進む（元に戻す・やり直し）
- **検索・置換**
- **関数を挿入**（`Ctrl+Shift+F`）
- **予測変換リストの編集**、**予測変換モード**

## タブ
「タブモードの表示」を有効にすると、複数のメモをタブで開けます。タブを右クリックすると「タブをグループ化する」「すべて閉じる」などが使えます。

## ツールメニュー
| 項目 | できること |
|---|---|
| AIの使用 | AIとチャット（Gemini）。下の「AIの使い方」を参照 |
| 読み上げ | メモを音声で読み上げ |
| 音声入力（マイク） | 声で文字を入力 |
| 文章統計・原稿用紙換算 | 文字数などの統計、原稿用紙に換算した枚数 |
| 行の整理 | 行の並べ替え・重複削除などの整形 |
| 文字変換 | 選択範囲の文字種などを変換 |
| 計算して挿入 | 全行・最終行・選択範囲を計算して挿入 |
| 日時・和暦スタンプ／日数計算 | 日付の挿入、日数の計算 |
| タイマー・ポモドーロ | タイマーとポモドーロ |
| ランダム | サイコロ・くじ・パスワード生成 |
| エンコード変換 | Base64・URL・JSONなどの変換 |
| 目標文字数 | 目標を決めて進み具合を見る |
| ウィンドウ化 | 別ウィンドウで表示（PCのみ） |

### AIの使い方
1. 「ツール」→「AIの使用」を開きます。
2. 「AIのAPIを入力」にAPIキーを入れ、モデル名を指定します。「暗号化して保存する（パスフレーズ）」で、保存時に暗号化できます。
3. 文章を変えたいときは、AIが「変更案」を出します。内容を見て **「適用する」を押すまで、削除・追加・書き換えは行われません**。選択範囲があればその部分、なければノート全体が対象です。
4. 「会話をリセット」で会話を最初から始められます。
5. 「サイトの内部コードを変更（危険）」は、HTMLそのものをAIに書き換えさせる機能です。最悪の場合サイトが壊れるので、通常は使わないでください。変更後のHTMLは「ダウンロード」するか、「このページで試す」（再読み込みで元に戻る）で確認します。

## 設定メニュー
- **WebGLの処理サイズ**（初期値130）、**WebGLの高速処理**: 計算・検索・文字数集計をGPUで実行
- **関数を追加する（JSファイル）**: 自作の関数を読み込み、「関数を挿入」から使えるようにします
- **関数を削除する（#の関数）**、**追加した関数の一覧**
- **フォントの表記**: 使っているフォントの表記を表示

## アプリ版だけの機能
- **ユーザー名**: 最初の起動で指定します（空のままだと `USER` + ランダム5桁）。設定メニューで変更できます。
- **HTTPで共有（モバイルデータ使用不可）**: 同じWi-Fi内でファイルを共有します。
  - 共有する側: ファイルメニューから「HTTPで共有」を選ぶと、QRと10桁のパスワードが出ます。「切断」で止めます。
  - 受け取る側: QRを読み取ると `/share?pw=...` が開き、「適用する」を押すとアプリが開きます。「共有リスト」フォルダに「ファイル名(ユーザー名)」で追加されます。
  - 書式は引き継がれず、内容はテキストとして保存されます。
- **自動バックアップ**: 5秒ごと（変化があったときだけ）に `memo-backup.json` へ保存し、メモが空のときは起動時に復元します。

## 注意
- フォント・アイコン・各ライブラリ（MiSans, Monaco, jsPDF など）はCDNから読み込むため、初回はネット接続が必要です。
- アプリ版でHTTP共有や音声入力を使うには、ビルドしたAPKか開発ビルドが必要です（Expo Goでは動きません）。

# norimemo（Expo / React Native版）V4.0.1

メモ帳のHTMLをWebViewで包んだアプリです。WebViewで動かないブラウザ機能は、アプリ側（ネイティブ）に橋渡ししています。

## 準備と実行
```
npm install
npx expo install --fix      # SDK 58に合うバージョンに自動で揃える（バージョンは仮指定のため必須）
```
**音声入力（マイク）とHTTP共有はネイティブモジュールを使うため、Expo Goでは動きません（アプリ側での検出・停止はせず、Expo側のエラーに任せます）。**
ビルドしたアプリ（APK）か、開発ビルドで使ってください。Expo Goでは、この2つ以外の機能は動きます。
```
eas build -p android --profile preview      # APKを作る
```

## 動くようにした機能
- **読み上げ**: expo-speech（Androidは一時停止に非対応のため、再開すると頭から読み直します）
- **音声入力（マイク）**: expo-speech-recognition
- **印刷・プレビュー**: expo-print（印刷画面、またはプレビュー画面から印刷）
- **共有・ダウンロード・バックアップ・書き出し**: ファイルをアプリ内の `exports` に保存し、共有シートから好きな場所へ保存
- **自動バックアップ**: 5秒ごと（変化時のみ）に `memo-backup.json` へ。メモが空のとき、起動時に復元
- **キーボード**: 開いたときに画面が崩れないよう、高さぶんWebViewを縮めます

## ユーザー名
最初の起動で「ユーザー名を指定してください(本名禁止)」が出ます。空のままOKにすると `USER` + ランダム5桁になります。設定メニューで変更できます。

## HTTPで共有（モバイルデータ使用不可）
ファイルメニュー →「HTTPで共有(モバイルデータ使用不可)」で、いま選択しているファイルを同じWi-Fi内に共有します。
- 共有する側: 「norimemoHTTPServer / 共有中 / QR / パスワード(10桁) / 切断」の画面が出ます。
- 受け取る側: QRを読み取ると、パスワード入力なしで `http://192.168.xx.xx:ポート5桁/share?pw=10桁` が開き、「ファイル共有」画面（ユーザー名・本文・「適用する」）が出ます。「適用する」を押すとアプリが開き、「共有リスト」フォルダが自動で作られて、そこに「ファイル名(ユーザー名)」で追加されます。
- パスワードなし、または違う場合はアクセスできません。受け取るのは同じネットワーク内の共有だけで、内容は必ずテキストとして保存されます（書式は引き継がれません）。
- 受け取る側にも norimemo アプリが必要です（ブラウザの画面から「適用する」でアプリが開きます）。

## メモ帳を更新したとき
`assets/index.html`（Expo用に変換済み）を差し替えて `npm run build:html`。

## 注意
- フォント・アイコン・各ライブラリ（MiSans, Monaco, jsPDF など）はCDNから読み込みます。**初回はネット接続が必要**です。
- `App.js` の `BASE_URL` を変えると、保存済みのメモが見えなくなります。
- `app.json` の `com.example.memoapp` は自分のIDに変えてください（公開後に変えると別アプリ扱いになります）。
